## The idea in one sentence

Find one solution of $Ax = b$, add every vector in the null space to it, and you have found them
all.

## One anchor, and the whole null space

Lecture 7.5 ended with a shape and no formula. The solutions of $Ax = b$ form an affine set, a
flat sheet pushed off the origin. That left one question open: what does the pushing?

The answer takes one line. Suppose $x_p$ is any single vector with $A x_p = b$. Call it the
particular solution. Suppose $x_n$ is any vector in the null space, so $A x_n = 0$. Then

$$
A(x_p + x_n) = A x_p + A x_n = b + 0 = b .
$$

So $x_p + x_n$ solves the system too. Every choice of $x_n$ gives a solution, and there are no
others: if $x$ and $x_p$ both solve the system then $A(x - x_p) = b - b = 0$, which puts
$x - x_p$ in the null space. Write $x_n = x - x_p$ and you are back where you started.

$$
x = x_p + x_n , \qquad x_n \in N(A) .
$$

One anchor, and a whole subspace of drift. Watch it in a case small enough to draw. Take

$$
A = \begin{bmatrix} 1 & 2 \\ 2 & 4 \end{bmatrix}, \qquad b = (3, 6) .
$$

The second row is twice the first, so both equations say the same thing, $x_1 + 2x_2 = 3$. One
solution is $x_p = (3, 0)$. The null space is the line through $x_n = (-2, 1)$, since
$-2 + 2 = 0$. The complete solution is $x = (3, 0) + t(-2, 1)$ for every real $t$.

## Does b even fit?

The recipe assumed a particular solution exists. Often it does not, and elimination tells you
which case you are in without any extra work. Put $b$ next to $A$ as one more column and reduce
the whole thing:

$$
A = \begin{bmatrix} 1 & 3 & 0 & 2 \\ 0 & 0 & 1 & 4 \\ 1 & 3 & 1 & 6 \end{bmatrix},
\qquad b = (1, 6, 7) .
$$

Row 3 of $A$ is row 1 plus row 2. Whatever the third equation claims, it is the sum of the first
two, so the only value of $b_3$ that can possibly work is $b_1 + b_2 = 7$. It is 7. Subtract rows
1 and 2 from row 3 of the augmented matrix and the last row goes completely flat, right side
included.

  The same matrix, two right-hand sides. Elimination flattens the third row either way, and what
  sits to the right of the divider decides everything. A zero there is the harmless statement
  $0 = 0$. Anything else is a contradiction, which is what the pink row is.
</Figure>

That is the whole consistency test. Reduce $[A \mid b]$, look at every row of the reduced matrix
that is all zeros on the left, and check that its right-hand entry is zero too. If one of them is
not, some combination of your equations says $0 = 1$ and no $x$ on earth will fix it.

When the test passes, the particular solution comes out almost for free. Set every free variable
to zero. In the reduced matrix above the pivots sit in columns 1 and 3, so $x_2$ and $x_4$ are
free. Setting both to zero leaves $x_1 = 1$ and $x_3 = 6$, which is exactly the right-hand column:

$$
x_p = (1, 0, 6, 0) .
$$

Check it: the first equation gives $1 + 0 + 0 + 0 = 1$, the second gives $0 + 0 + 6 + 0 = 6$, and
the third gives $1 + 0 + 6 + 0 = 7$. Now add the null space. The free columns give two special
solutions by the method of Lecture 7.5, $s_1 = (-3, 1, 0, 0)$ and $s_2 = (-2, 0, -4, 1)$, so the
complete solution is

$$
x = (1, 0, 6, 0) + c\,(-3, 1, 0, 0) + d\,(-2, 0, -4, 1) .
$$

An anchor in $\R^4$, plus a two-dimensional sheet of drift, for any $c$ and $d$ you like.

```python
import numpy as np

A = np.array([[1., 3., 0., 2.],
              [0., 0., 1., 4.],
              [1., 3., 1., 6.]])       # row 3 = row 1 + row 2
b = np.array([1., 6., 7.])             # and 7 = 1 + 6, so it fits

M = np.hstack([A, b.reshape(-1, 1)])   # the augmented matrix
M[2] -= M[0] + M[1]                    # the only step elimination needs
print(M)                    # [[1. 3. 0. 2. 1.]
                            #  [0. 0. 1. 4. 6.]
                            #  [0. 0. 0. 0. 0.]]   <- 0 = 0, consistent

xp = np.array([1., 0., 6., 0.])        # free variables set to zero
s1 = np.array([-3., 1., 0., 0.])       # switch on x2
s2 = np.array([-2., 0., -4., 1.])      # switch on x4
print(A @ xp, A @ s1, A @ s2)          # [1. 6. 7.] [0. 0. 0.] [0. 0. 0.]
for c, d in [(0., 0.), (2., -1.), (-0.5, 3.)]:
    print(A @ (xp + c * s1 + d * s2))  # [1. 6. 7.] every time

bad = np.array([1., 6., 8.])           # 8 is not 1 + 6
Mbad = np.hstack([A, bad.reshape(-1, 1)])
Mbad[2] -= Mbad[0] + Mbad[1]
print(Mbad[2])                         # [0. 0. 0. 0. 1.]  <- 0 = 1, no good
print(np.linalg.matrix_rank(A), np.linalg.matrix_rank(Mbad))   # 2 3
```

## Rank

Everything above turned on two counts: how many pivots the matrix has, and how many columns are
left over. The first count has a name.

The **rank** $r$ of a matrix is the number of pivots elimination produces. Equivalently, it is the
number of columns that carry information no earlier column already carried, which makes it the
dimension of the column space $C(A)$. The rows tell the same story, so $r$ is also the dimension
of the row space $C(A\T)$. That last claim is the one surprise in this chapter, and Lecture 9
proves it properly.

Two consequences you already used. The null space has dimension $n - r$, one direction per free
column. And a system has a solution exactly when adding $b$ as an extra column leaves the rank
alone, since a column that raises the rank is a column the old ones could not reach. So $Ax = b$
is solvable precisely when

$$
\rank\begin{bmatrix} A & b \end{bmatrix} = \rank A .
$$

Rank is bounded by both dimensions, so $r \le m$ and $r \le n$. Those two comparisons, each either
tight or slack, sort every matrix into four cases.

**Case 1, $r = m = n$.** Square with a pivot in every row and column. No free columns means
$N(A) = \lbrace 0 \rbrace$ and no drift, and no zero rows means $b$ always fits. Exactly one
solution, for every $b$. Take

$$
A = \begin{bmatrix} 1 & 2 \\ 3 & 8 \end{bmatrix}, \qquad b = (5, 17) .
$$

Eliminate and back-substitute to get $x = (3, 1)$, and check: $3 + 2 = 5$ and $9 + 8 = 17$. There
is nothing to add, because the null space holds only the zero vector. This is the invertible case
from Lecture 5, seen from the rank side.

**Case 2, $r = m < n$.** Short and wide with a pivot in every row, so
elimination never produces a zero row and $b$ always fits. But $n - r$ free columns remain, so the
answer is never unique. Infinitely many solutions, for every $b$. Take

$$
A = \begin{bmatrix} 1 & 2 & 3 \\ 0 & 1 & 4 \end{bmatrix}, \qquad b = (6, 5) .
$$

Subtract twice row 2 from row 1 to reach $R = \begin{bmatrix} 1 & 0 & -5 \\ 0 & 1 & 4
\end{bmatrix}$ and $d = (-4, 5)$. Column 3 is free, so $x_p = (-4, 5, 0)$ and $s = (5, -4, 1)$.
Check the special solution: $5 - 8 + 3 = 0$ and $0 - 4 + 4 = 0$. The complete solution is
$(-4, 5, 0) + t\,(5, -4, 1)$.

**Case 3, $r = n < m$.** Tall and thin with a pivot in every column. No free columns means at most
one solution, and the leftover rows mean $b$ has to cooperate. No solution or exactly one. Take

$$
A = \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ 1 & 1 \end{bmatrix} .
$$

Its column space is the plane of all $(u, v, u+v)$, which is the set of vectors satisfying
$b_1 + b_2 - b_3 = 0$. So $b = (2, 3, 5)$ works, with the unique answer $x = (2, 3)$, and
$b = (2, 3, 6)$ does not, because $2 + 3 - 6 = -1$. One extra unit in the third slot and the
target lifts clean off the plane.

**Case 4, $r < m$ and $r < n$.** Neither full. Free columns bring back the drift, leftover rows
bring back the consistency test, and you get the worst of both. No solution, or infinitely many.
This case is usually left symbolic. Here it is with real numbers:

$$
A = \begin{bmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \\ 1 & 2 & 4 \end{bmatrix} .
$$

Row 2 is twice row 1, so $r = 2$ while $m = n = 3$. With $b = (1, 2, 3)$ the second equation is
twice the first, which is consistent, and subtracting the first equation from the third gives
$x_3 = 2$, leaving $x_1 + 2x_2 = -5$. One answer is $x_p = (-5, 0, 2)$, the null space is the line
through $(-2, 1, 0)$, and the complete solution is $(-5, 0, 2) + t\,(-2, 1, 0)$. Check the anchor:
$-5 + 0 + 6 = 1$, then $-10 + 0 + 12 = 2$, then $-5 + 0 + 8 = 3$. With $b = (1, 3, 3)$ instead,
the second equation demands 3 where the first forces 2. Nothing works.

<Callout type="intuition">
  Read the two questions off the shape of $R$ and you never have to solve anything to know what
  to expect. Free columns on the right of $R$ mean the answer set has room to move. Zero rows at
  the bottom of $R$ mean $b$ has to pass an exam first. Case 1 has neither, case 4 has both.
</Callout>

## The measurements table

Here is a table you will meet again. Five people, two measurements each, and one target column:

| weight $w$ | height $h$ | target |
| --- | --- | --- |
| 5 | 2 | 3 |
| 3 | 4 | 8 |
| 2 | 8 | 7 |
| 1 | 5 | 9 |
| 4 | 7 | 2 |

The question is the one from Lecture 1, asked with real data. Is there a pair of numbers
$x = (x_1, x_2)$ with $x_1 w + x_2 h$ equal to the target column? That is $Ax = b$ with $A$ the
5 by 2 matrix of measurements, so $m = 5$ and $n = 2$. The two columns are independent, so $r = 2$
and this is case 3: tall and thin, no solution or exactly one.

It is the no-solution branch. The rank of $A$ is 2 and the rank of $A$ with the target attached is
3, so the target column adds something the measurements never had. In geometry: $C(A)$ is a
two-dimensional plane sitting inside $\R^5$, and the target sits off it.

```python
import numpy as np

square = (np.array([[1., 2.], [3., 8.]]), np.array([5., 17.]))
```

## Basis, independence, dimension

Three words have been doing quiet work throughout, and they deserve one paragraph each.

Vectors $v_1, \dots, v_k$ are **independent** when the only combination of them equal to zero is
the one with all coefficients zero. Stack them as the columns of a matrix and that sentence
becomes a null space statement: the columns are independent exactly when $N(A) = \lbrace 0 \rbrace$.
Free columns are the dependent ones, and each free column hands you a nonzero vector in the null
space that proves the dependence.

A set **spans** a space when every vector in that space is some combination of the set. A **basis** is a
set that does both jobs, independent and spanning. Independence keeps it from being wasteful and
spanning keeps it from being short, and together they buy you something worth having: in terms of
a basis, every vector in the space has exactly one recipe. Two different recipes for the same
vector would subtract to a nonzero combination equal to zero.

Every basis of a given space has the same number of vectors, and that number is the **dimension**.
For $C(A)$ the pivot columns of $A$ form a basis, so the dimension is $r$. For $N(A)$ the special
solutions form a basis, so the dimension is $n - r$. The space $\lbrace 0 \rbrace$ has dimension 0
and its basis is the empty set, which is the only sensible answer: the zero vector can never
belong to a basis, since $1$ times it is already a nonzero combination equal to zero.

## Where this is going

Count the dimensions on both sides of $A$. On the input side $\R^n$ holds the null space with
$n - r$ dimensions and the row space $C(A\T)$ with $r$. On the output side $\R^m$ holds the
column space $C(A)$ with $r$, and one more space: the vectors $y$ with $A\T y = 0$. That one is
the left null space $N(A\T)$, and it has $m - r$ dimensions. Four spaces, two on each side, and
the counts add up exactly.
