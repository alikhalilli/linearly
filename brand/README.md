# Brand assets

Social images for linearly, generated from the site's own identity (the yellow
wordmark chip, the neobrutal card system, the four-subspaces hero art) by
`node scripts/generate-social.mjs`. Each is laid out at the platform's display
size and rendered at 2x device pixels, so it stays sharp on retina screens.
Edit the script and regenerate; never edit the PNGs.

| File | Pixels | Displays at | Use |
|---|---|---|---|
| `logo.png` | 2048 x 2048 | 1024 square | avatar everywhere; survives a circular crop |
| `cover-x.png` | 3000 x 1000 | 1500 x 500 | X header |
| `cover-linkedin.png` | 2256 x 382 | 1128 x 191 | LinkedIn company-page banner (left edge stays clear of the page logo) |
| `cover-instagram.png` | 2160 x 2160 | 1080 square | Instagram post |
